# Brrr

For anyone with a clear coding task: Brrr has one agent do the work with visible progress, focused checks, and a self-review at the end, without a heavier multi-agent workflow.

## When to use it

Reach for it for everyday implementation when the outcome and acceptance criteria are already clear, such as an approved brief, plan, spec, or ticket. When the request still needs decisions, settle them first with [Lock In](lock-in.md).

## What you get

The change itself, progress you can follow while it works, the checks it ran to confirm the result, and a short self-review of what it built.

## Install

```sh
npx skills@latest add javonmcgilberry/skills --skill brrr
```

Other ways to install are in [the README](../README.md#install). The skill's instructions are in [skills/brrr/SKILL.md](../skills/brrr/SKILL.md).
