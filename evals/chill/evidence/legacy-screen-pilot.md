# Retained directional evidence

The earlier `chill-screen-2026-07-29-v1` run compared the three workflows relevant to the current question across five communication tasks, with one candidate per arm and model grading.

| Arm | Mean score | Mean words | Critical caps |
| --- | ---: | ---: | ---: |
| Normal | 4.532 | 233.8 | 1 |
| Chill upfront | 4.549 | 140.8 | 1 |
| Chill afterward | 4.539 | 230.4 | 1 |

The afterward rewrites retained every requirement that the normal answers contained and introduced no new omissions according to that run's grader. On the dense architecture case, Chill upfront scored 4.925 in 240 words, while Chill afterward scored 4.835 in 586 words.

This evidence is useful but insufficient. It suggests that Chill upfront can shorten answers without an obvious aggregate quality loss, but the run had one trial, relied on a model judge, and was built around supplied-fact communication tasks. It did not adequately measure source use, citation retention, or whether Chill changes the substantive research and planning result.

The old raw project is preserved in the pre-cleanup backup named in the final cleanup report. It is not active evidence for the focused decision.
