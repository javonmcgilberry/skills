# React references

- [You Might Not Need an Effect](https://react.dev/learn/you-might-not-need-an-effect)
  covers derived values, events, state resets, effect chains, initialization,
  and fetching.
- [useEffect](https://react.dev/reference/react/useEffect) defines effect setup,
  cleanup, dependencies, and external-system synchronization.
- [useSyncExternalStore](https://react.dev/reference/react/useSyncExternalStore)
  provides concurrent-safe external store subscriptions.
- [useEffectEvent](https://react.dev/reference/react/useEffectEvent) reads
  non-reactive values from a valid effect without hiding reactive dependencies.
